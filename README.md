# OctaBitLogics Portfolio

A modern, high-performance portfolio application built with Next.js 16, React 19, Framer Motion, and Tailwind CSS v4.

## 🚀 Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **UI & Components:** [React 19](https://react.dev/), [Lucide Icons](https://lucide.dev/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Analytics:** Vercel Analytics & Speed Insights
- **Email:** Nodemailer

## 📁 Project Structure

```
octabitlogic/
├── src/
│   ├── app/           # Next.js App Router pages and API routes
│   ├── components/    # Reusable UI components (Hero, Services, Case Studies, etc.)
│   ├── data/          # Portfolio data and static content
│   └── lib/           # Utility functions and shared helpers
├── public/            # Static assets and media files
├── package.json       # Project dependencies and scripts
└── next.config.js     # Next.js configuration
```

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Build & Deployment

Build the application for production:

```bash
npm run build
```

Start the production server:

```bash
npm run start
```
